# Manifest: where each figure, table and number comes from

This file maps every table and figure of the article *Regime shift, rising runoff efficiency and sparse gauging: limits to testing drought propagation in a Sahel–savanna landscape* and of its Supplementary Material to the derived files shipped in this repository and to the script that writes them. The same information is in machine-readable form in `manifest/tables.csv` and `manifest/figures.csv`. Reported numbers are checked one by one by `verify_manuscript_numbers.py` (report in `verification/verification_report.md`).

Status codes:

* **S**: regenerated by a script in this release (`reproduce.sh`); the derived file is shipped, so the values can be checked without the GRDC records.
* **X**: drawn from a derived table produced in an earlier, separate workflow; the table is shipped in `figures_pub/supp_tables/`, the extraction script is not part of this release.
* **V**: values from a separate analysis whose inputs cannot be redistributed or are not part of this release; neither script nor table is shipped.
* **N**: descriptive table without computed values.

Of the 37 tables, 34 are status S, 1 X, 0 V and 2 N.
